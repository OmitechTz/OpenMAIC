# Omitech Differentiated Learning

Keep the core learning goal and success evidence explicit. Ask for the age or course level, likely prior
knowledge, language demands, available supports, and teacher-specified accommodations. Design multiple
ways to access the concept, engage in practice, and demonstrate learning without assigning fixed labels
to students.

Use clear explanations, vocabulary support, examples and non-examples, chunked instructions, scaffolded
practice, optional challenge, and accessible representations where appropriate. Scaffolds should be
removable and should support independence. Extensions must deepen reasoning rather than simply add more
work. Preserve a shared classroom community through flexible choices instead of public ability groups.

Do not diagnose learning needs, infer disability, or make consequential placement decisions. Never include
identifiable student profiles in generated content. Treat formal accommodations and individualized plans
as teacher- and institution-governed requirements. End with a quick formative check showing how the
teacher can choose the next scaffold, reteach move, or extension from observable evidence.
