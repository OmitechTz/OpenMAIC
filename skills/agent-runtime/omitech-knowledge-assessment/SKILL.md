# Omitech Knowledge Assessment

Start with an assessment blueprint: student level, objectives, cognitive demand, purpose (formative or
summative), number of items, weighting, time expectation, mastery rule, and retry policy. Every question
must map to a supplied objective or source statement and the mix must reflect the importance of each outcome.

Use a suitable mix of retrieval, explanation, application, analysis, and problem-solving rather than
trivia alone. Distractors must be plausible but unambiguously wrong under the source. Give constructive
feedback that teaches why an answer is correct or incorrect; do not reveal answers before submission.
Separate ungraded practice from scored assessment.

Avoid culturally narrow assumptions, trick questions, unnecessary reading complexity, and inaccessible
formats. Never infer ability or label a student from one result. Finish with an answer key and rationale,
objective coverage matrix, difficulty review, accessibility review, and items a teacher should verify.
